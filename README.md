# Notas App

Aplicación web para guardar notas. Los datos se almacenan en una base de datos PostgreSQL.

## Tecnologías

- HTML, CSS y JavaScript (frontend)
- Node.js y Express (servidor)
- PostgreSQL (base de datos)

## Cómo ejecutarlo

1. Instalar dependencias: npm install
2. Crear un archivo .env con la línea: DATABASE_URL=tu_cadena_de_conexion
3. Iniciar el servidor: npm start
4. Abrir http://localhost:3000
