# Notas App

Aplicación web para guardar notas. Los datos se almacenan en una base de datos SQLite en el servidor.

## Tecnologías

- HTML, CSS y JavaScript (frontend)
- Node.js y Express (servidor)
- SQLite (base de datos)

## Cómo ejecutarlo

1. Instalar dependencias: npm install
2. Iniciar el servidor: node server.js
3. Abrir http://localhost:3000
